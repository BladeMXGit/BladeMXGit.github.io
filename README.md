# 📈 Finanzas Inteligentes - Portal Web Automatizado con IA

Un portal web moderno, ultra-rápido y optimizado para **SEO y Google AdSense**, diseñado para generar ingresos pasivos mediante tráfico orgánico de búsqueda en Google.

---

## 🚀 Características del Sistema

1. **Nicho de Alto RPM:** Centrado en *Finanzas Personales, Impuestos, Ahorro e Inversión* (uno de los nichos que más paga por clic en Google AdSense: entre **15 € y 25 € por cada 1.000 visitas**).
2. **Generación Diaria Automatizada:** Un flujo de trabajo en la nube de GitHub Actions genera y actualiza nuevos artículos todos los días sin intervención manual.
3. **Optimizado para Google (SEO 100/100):**
   - Marcado de datos estructurados Schema.org (`Article`).
   - Mapa del sitio XML automático (`sitemap.xml`).
   - Archivo `robots.txt` para rastreadores.
   - Páginas legales obligatorias para aprobación de AdSense (`Aviso Legal`, `Privacidad`, `Cookies`).
4. **Espacios Publicitarios Integrados:** Listo para colocar tu ID de editor de Google AdSense (`ca-pub-XXXXXXXXXXXXXXXX`).

---

## 💰 Cómo Activar Google AdSense

1. Entra en [Google AdSense](https://www.google.com/adsense/) e inicia sesión con tu cuenta de Google.
2. Añade tu sitio web: `https://blademasterlol.github.io/finanzas-inteligentes/`.
3. Copia tu código de editor (`ca-pub-XXXXXXXXXX`).
4. Reemplaza el ID en `generator.py` y vuelve a compilar con:
   ```bash
   python generator.py
   ```
5. Google revisará la web y, una vez aprobada, comenzará a mostrar anuncios y depositarte los ingresos mensuales directamente en tu cuenta bancaria.
